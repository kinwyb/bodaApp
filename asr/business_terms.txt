# 业务词表：每行一个**正确写法**，用 # 注释。
#
# 格式：正确写法 | 别名1 | 别名2
#   别名可选，是「确定会被念成/写成这样」的补充写法。
#
# 用途不是「替换这句话里的错字」，而是给纠错器一份领域词库：
# 识别结果里任何与这些词**拼音相近、字数相同**的片段，都会被换成正确写法。
# 所以词要来自业务本身（物料类型、包装方法、字段名），而不是从某句错误里抄。
#
# 什么时候才需要写别名：目标词含英文/数字时（拼音匹配不到），
# 或者某个错法读音差得太远。纯中文词一般不用写，近似读音会自动命中。
#
# 宁可少写，不要写会误伤的通用词（「数量」「方法」这种到处都对的词，
# 写进来只会把正常文本改坏）。
#
# 改完不用重建镜像：docker compose restart asr
